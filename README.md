## ⚡ How to Export & Upload to GitHub (Easy Guide)

### Option A: Via GitHub Website (Zero Command-Line / 1 Minute)
1. Go to [github.com](https://github.com) and click **"New Repository"**.
2. Give it a name, e.g. `akash-ai-nexus`.
3. Leave it Public or Private, and do **NOT** initialize with a README (we already have a complete one).
4. Click **"Create repository"**.
5. On the empty repo page, click **"uploading an existing file"**.
6. Extract the `akash-ai-nexus-github-ready.zip` (or drag all files from this project folder except `node_modules` and `dist`) directly into the GitHub web page.
7. Click **"Commit changes"**. Your project is now 100% live on GitHub!

---

### Option B: Via Git Command Line
```bash
# 1. Initialize git
git init

# 2. Add all files
git add .

# 3. Create initial commit
git commit -m "feat: complete Akash AI Nexus with 106 AI models and Vexta UI"

# 4. Link your GitHub repository
git remote add origin https://github.com/YOUR_USERNAME/akash-ai-nexus.git

# 5. Push to GitHub
git branch -M main
git push -u origin main
```

## 🛠️ Local Development & Build

### Prerequisites
- Node.js (v18 or v20+)
- npm or pnpm

### Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev
# Server will launch at: http://localhost:5173/

# 3. Build optimized production bundle
npm run build
```
